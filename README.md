# Орбита

Демонстрационный лендинг о творчестве. HTML, CSS и JavaScript без зависимостей. Кнопка «Ещё одна идея» меняет упражнение.

## Адрес и публикация

Репозиторий: https://github.com/leyka22/landing
Ожидаемый адрес после включения GitHub Pages: https://leyka22.github.io/landing/

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
Дождитесь успешной публикации в Actions. Действующий адрес появится в Settings → Pages.

GitHub Pages — бесплатный статический хостинг для публичных репозиториев. leyka22.github.io — поддомен GitHub, а не отдельный зарегистрированный домен.

## Управление

- Тексты и разделы: index.html.
- Цвета и адаптивная вёрстка: style.css.
- Список упражнений: script.js.
- Для локального просмотра откройте index.html в браузере.
- Сохранение изменений коммитом в main автоматически обновляет включённый сайт Pages.
- Статус публикации: Actions. Адрес и HTTPS: Settings → Pages.
- Отключение публикации: Settings → Pages → Unpublish site.

Документация: https://docs.github.com/en/pages/quickstart
